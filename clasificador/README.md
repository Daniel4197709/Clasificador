# 🐾 Clasificador de Animales con Teachable Machine

Esta es una aplicación web interactiva que utiliza tu modelo entrenado en Google Teachable Machine:
[https://teachablemachine.withgoogle.com/models/DrlS9wpXm/](https://teachablemachine.withgoogle.com/models/DrlS9wpXm/)

## 🚀 Características
- **Subir o arrastrar fotos**: Prueba con cualquier imagen de animal guardada en tu equipo (JPG, PNG, WebP).
- **Cámara Web en tiempo real**: Clasificación instantánea cuadro por cuadro usando la cámara de tu computadora o celular.
- **Gráficos interactivos de confianza**: Barras animadas con el porcentaje de probabilidad para cada clase.
- **Predicción destacada**: Resalta inmediatamente el animal detectado con mayor probabilidad.
- **Diseño moderno y adaptable**: Funciona en computadoras, tablets y teléfonos móviles.

## 💡 Cómo abrir la página web
1. **Opción 1 (Recomendada para usar la Cámara Web):**
   Haz doble clic sobre el archivo `iniciar.bat`. Esto abrirá un servidor local seguro en `http://localhost:8000` para que el navegador permita acceder a la cámara sin bloqueos de seguridad.
2. **Opción 2 (Rápida para subir fotos):**
   Haz doble clic directamente sobre `index.html` para abrirlo en tu navegador favorito (Chrome, Edge, Firefox, etc.).
